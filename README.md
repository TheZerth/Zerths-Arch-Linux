# Zerths-Arch-Linux

Arch Linux / Hyprland installation and configuration script for a minimal, robust, dark-stone TUI-oriented desktop.

## Design reference

- [Theme Style Guide](THEME_STYLE_GUIDE.md) — Lapis Obscura: dark basalt, Gruvbox mineral accents, lo-fi wizardry, sacred geometry, and minimal Hyprland/TUI theming guidance.
- [Hermes skin](hermes/skins/lapis-obscura.yaml) — custom Hermes CLI skin generated from the style guide.
- [Foot theme](foot/foot.ini), [Fish theme](fish/conf.d/20-lapis-obscura.fish), and [Fuzzel theme](fuzzel/fuzzel.ini) — terminal, shell, and launcher theme configs installed by the script.
- [Wallpapers](wallpapers/README.md) — saved references, custom generated Lapis Obscura wallpapers, and Hyprpaper setup notes.
