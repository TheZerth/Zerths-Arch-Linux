# ZerthArchInstall.sh — Function Reference

## Package Management

### `ensureParuWorks`
Checks whether `/usr/bin/paru` is present. If not, bootstraps paru by cloning `paru-bin` from the AUR into a temporary directory, building it as `$InstallUser` with `makepkg`, and installing the resulting package with `pacman -U`. Aborts if the install user is root (paru cannot be built as root). Cleans up the build directory on success.

### `installRepoPackages [pkg…]`
Installs official-repository packages as root via `pacman -S --needed --noconfirm`. Skips packages that are already installed and prints a status line. Use this for any package available in the official Arch repos (`[core]`, `[extra]`, `[multilib]`).

### `installAurPackages [pkg…]`
Installs AUR packages as the target user via `paru -S --needed --noconfirm --skipreview`. Calls `ensureParuWorks` first, skips already-installed packages, and prints a status line. Aborts if the install user is root.

### `handleRemove pkg`
Checks whether `pkg` is installed. If found, removes it and its unneeded dependencies with `pacman -Rns --noconfirm`. Continues on failure rather than aborting the script.

---

## User / Process Helpers

### `runAsInstallUser [command…]`
Runs a command as the detected install user (`$InstallUser`). When the script is running as root and the install user is not root, it uses `sudo -u` with a correctly set `HOME` and `XDG_RUNTIME_DIR`. Otherwise it runs the command directly.

### `waitForHyprlandExit pid`
Polls `kill -0` up to 30 times (1-second intervals) waiting for the Hyprland process to exit naturally. If it is still alive after 30 seconds, it sends a `SIGTERM` and waits for the process to be reaped.

## NVIDIA Configuration

### `configureNvidiaInitramfs`
Adds the four NVIDIA kernel modules (`nvidia`, `nvidia_modeset`, `nvidia_uvm`, `nvidia_drm`) to the `MODULES=()` array in `/etc/mkinitcpio.conf`, avoiding duplicates, then regenerates all presets with `mkinitcpio -P`.

### `setNvidiaPersistenceMode`
Calls `nvidia-smi -pm 1` to enable NVIDIA persistence mode. Skips gracefully if `nvidia-smi` is not found or the command times out (10 s), printing a hint that a reboot may be needed.

### `setNvidiaPowerMizerMode`
Calls `nvidia-settings -a "[gpu:0]/GpuPowerMizerMode=1"` to force maximum performance. Skips gracefully if `nvidia-settings` is not found or no control display is available.

### `setNvidiaPowerMizerModeInHyprland`
Same goal as `setNvidiaPowerMizerMode`, but dispatches the command into a live Hyprland session via `hyprctl dispatch exec` so the display is available. Falls back silently if the Hyprland socket is unreachable.

---

## SSH Key Setup

### `copySshKeysFromUsb`
Prompts the user to plug in a USB drive, mounts `/dev/sda1` at a temporary path, copies the `.ssh` directory from the drive root to `$InstallHome/.ssh`, sets correct permissions (`700` on directories, `600` on files), and fixes ownership to `$InstallUser`. Unmounts and cleans up the temporary mount point on success or failure.

---

## Hyprland Config Helpers

### `ensureHyprLine line config`
Appends `line` verbatim to `config` only if an exact match is not already present (`grep -qxF`). Used to safely add `env =`, `exec-once =`, and `bind =` directives without creating duplicates.

### `setHyprBlockOption block option value config`
Finds a named block (e.g. `general { … }`) in a Hyprland config file and either updates an existing `option = …` line inside it or inserts a new one. If the block does not exist at all, it appends a new block with the option. Special regex characters in block/option names are escaped before use.

---

## Hyprland & Desktop Configuration

### `configureSamsungOledG8Monitor config`
Removes any previous auto-generated `monitor =` default and any prior `# Zerth Samsung OLED G8 monitor` block, then appends a `monitorv2 { … }` block tailored for the Samsung OLED G8 (3440×1440 @ 120 Hz, 10-bit, HDR, VRR enabled). The output connector can be pinned via the `ZERTH_HYPR_MONITOR_OUTPUT` environment variable.

### `configureHyprpaperConfig`
Creates `~/.config/hypr/hyprpaper.conf` if it does not exist, or idempotently updates the `preload`, `wallpaper`, and `splash` entries if it does. The wallpaper path defaults to `~/Pictures/wallpaper.png` and can be overridden with `ZERTH_HYPRPAPER_WALLPAPER`.

### `configureEwwConfig`
Writes three files into `~/.config/eww/`:

| File | Purpose |
|---|---|
| `zerth-status.sh` | Status polling script exposing sub-commands: `time`, `date`, `audio`, `network`, `workspace`, `memory`, `cpu` |
| `eww.yuck` | Eww widget definitions — a full-screen overlay with a top info panel and a bottom control panel |
| `eww.scss` | Stone/dark colour-scheme styles for all Eww widgets |

### `configureHyprlandConfig`
Comprehensive Hyprland setup. Key actions:

- Copies the default config from `/usr/share/hypr/hyprland.conf` if none exists.
- Disables `autogenerated` flag, logo, splash, shadows, blur, and animations.
- Sets gaps, border size, and gradient border colours.
- Enables color management (`cm_enabled`, `cm_fs_passthrough`, `cm_auto_hdr`, `use_fp16`).
- Calls `configureSamsungOledG8Monitor` for the monitor block.
- Sets `$terminal = foot`, `$fileManager = pcmanfm-qt`, `$menu = fuzzel`.
- Appends all required NVIDIA + Wayland environment variables.
- Adds `exec-once` startup entries for `dbus`, `systemd`, `hyprpolkitagent`, `xdg-desktop-portal`, `dunst`, `hyprpaper`, `eww`, `udiskie`, and `cliphist`.
- Removes the deprecated `ashell` and `monique` autostart lines.
- Binds hotkeys for the clipboard manager, file manager, launcher, Eww overlay toggle, and session exit.
